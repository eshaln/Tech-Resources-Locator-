How Should You Use These Resources?

I'm completely new to AI

Start with Python and basic mathematics. Then move into introductory machine learning before attempting deep learning.

I already know Python

Start with Google's Machine Learning Crash Course or Kaggle's introductory machine learning course, then move into deep learning.

I want practical AI development

Prioritize courses that require you to build models and applications. fast.ai is particularly useful for this approach.
